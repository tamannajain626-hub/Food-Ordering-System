# Food Ordering System — Phase 1 (Customer Registration)

A small RDBMS mini-project. **Goal:** registering a customer inserts a row into MySQL
and MySQL generates a unique `customer_id` for it.

**Stack:** HTML / CSS / JS (frontend — *not built yet*), Java Spring Boot + Maven (backend), MySQL.

---

## 1. What you need installed

| Tool | Version used | Check with |
|---|---|---|
| JDK | 17 or newer (21 recommended) | `java -version` |
| Maven | 3.8 or newer | `mvn -v` |
| MySQL | 8.0 or newer | `mysql --version` |

## 2. Set up the database

The app talks to a database named **`food_ordering`**.

### Step 2.1 — Create the database

Run this once (it will ask for your MySQL password):

```bash
/usr/local/mysql/bin/mysql -u root -p < src/main/resources/db/create-database.sql
```

Or paste this straight into the MySQL prompt:

```sql
CREATE DATABASE IF NOT EXISTS food_ordering
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
```

> You do **not** need to create the `customer` table yourself.
> Hibernate creates it automatically when the app starts (see section 5).

### Step 2.2 — Tell the app your MySQL password

The password is **never written into the project**. It is read from environment
variables, which you set in your terminal.

```bash
export DB_USERNAME=root
export DB_PASSWORD=your_real_password_here
export DB_URL="jdbc:mysql://localhost:3306/food_ordering?createDatabaseIfNotExist=true&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC"
```

| Variable | Required? | Default if you skip it |
|---|---|---|
| `DB_USERNAME` | recommended | `root` |
| `DB_PASSWORD` | **yes** | *(empty)* — the app will fail to connect |
| `DB_URL` | no | `jdbc:mysql://localhost:3306/food_ordering?...` |

You can also skip `DB_URL` entirely if MySQL runs on `localhost:3306` with the
database `food_ordering`.

**Tip — save it for next time:** copy the provided `.env.example` to `.env`,
put your real password in it, and `source` it before each run:

```bash
cp .env.example .env
nano .env          # type your password, then Ctrl+O, Enter, Ctrl+X
source .env        # loads the variables into this terminal
mvn spring-boot:run
```

`.env` is already listed in `.gitignore`, so your password will never be
committed or shared.

## 4. The website

### Register a customer — http://localhost:8080/

Fill in **Full name**, **Email address** and **Phone number**, then press
**Register**.

* If everything is fine, the page shows a green box with the ID that MySQL
  generated, e.g. `Customer ID: 5`.
* If the email is already registered, a red box appears and the email field is
  marked.
* If a field is empty or the email/phone format is wrong, a red message
  appears under that field.

### View customers — http://localhost:8080/customers.html

A table with **Customer ID | Name | Email | Phone**, read live from MySQL with
`GET /api/customers`. Press **Refresh** to reload the list.

### How the frontend talks to the backend

`js/register.js` sends a `POST` request with `fetch()`:

```javascript
fetch("/api/customers", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(customer)
})
```

`js/customers.js` sends a `GET` request the same way. Because the pages are
served by the same Spring Boot application, the URL is simply `/api/customers`
— no CORS setup and no separate web server needed.

## 5. Try the API from the command line

### Register a customer — `POST /api/customers`

```bash
curl -X POST http://localhost:8080/api/customers \
  -H "Content-Type: application/json" \
  -d '{"name":"Tamanna Rahman","email":"tamanna@example.com","phone":"9876543210"}'
```

**Response — `201 Created`:**

```json
{
  "customerId": 1,
  "name": "Tamanna Rahman",
  "email": "tamanna@example.com",
  "phone": "9876543210"
}
```

`customerId` was generated by MySQL's `AUTO_INCREMENT` — you never sent it.

### List all customers — `GET /api/customers`

```bash
curl http://localhost:8080/api/customers
```

**Response — `200 OK`:**

```json
[
  { "customerId": 1, "name": "Tamanna Rahman", "email": "tamanna@example.com", "phone": "9876543210" },
  { "customerId": 2, "name": "Rahim Uddin",   "email": "rahim@example.com",    "phone": "9123456780" }
]
```

### Errors

| Situation | Status | Body |
|---|---|---|
| Email already registered | `409 Conflict` | `{"message":"A customer with email '...' already exists"}` |
| Invalid email format | `400 Bad Request` | `{"message":"Validation failed","errors":{"email":"Email must be a valid email address"}}` |
| Blank name | `400 Bad Request` | `{"errors":{"name":"Name is required"}}` |
| Phone not 10 digits | `400 Bad Request` | `{"errors":{"phone":"Phone must be exactly 10 digits"}}` |

## 5. How the table is created

`src/main/resources/application.properties` contains:

```properties
spring.jpa.hibernate.ddl-auto=update
```

On startup Hibernate issues the `CREATE TABLE` for you. The table it creates is
exactly this:

```sql
CREATE TABLE `customer` (
  `customer_id` bigint NOT NULL AUTO_INCREMENT,
  `email` varchar(100) NOT NULL,
  `name` varchar(100) NOT NULL,
  `phone` varchar(20) NOT NULL,
  PRIMARY KEY (`customer_id`),
  UNIQUE KEY `UKdwk6cx0afu8bs9o4t536v1j5v` (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

The three annotations in `Customer.java` produce that table:

```java
@Id                                   // primary key
@GeneratedValue(strategy = GenerationType.IDENTITY)   // MySQL AUTO_INCREMENT
@Column(name = "customer_id")
private Long customerId;
```

Because the id is `AUTO_INCREMENT`, the SQL Hibernate logs contains **no id column**:

```sql
insert into customer (email, name, phone) values (?, ?, ?)
```

and MySQL fills `customer_id` in. The `UNIQUE` key on `email` is the safety net
that guarantees one row per email address even if two people register at the
same instant.

> `spring.jpa.show-sql=true` is on, so every SQL statement is printed in the
> terminal. Handy for showing your teacher exactly what ran.

## 9. Troubleshooting

**The website shows "Could not reach the server"**
The backend is not running. Start it with `mvn spring-boot:run` and wait for
*"Started FoodOrderingApplication"*.

**The page is blank / "No static resource ."**
The app was started **before** the `static/` folder existed, so Spring Boot did
not register the home page. Stop the app (`Ctrl+C`) and start it again.

**`Access denied for user 'root'@'localhost' (using password: NO)`**
Your `DB_USERNAME` / `DB_PASSWORD` are wrong or were not set in the terminal
that started the app. The phrase "(using password: NO)" means the password was
**empty** — you probably forgot to `export DB_PASSWORD=...` or `source .env`.
Re-export them and start the app again.

**`Access denied for user 'root'@'localhost' (using password: YES)`**
The password was sent but MySQL rejected it. Your password is wrong, or the
MySQL user does not have access to the `food_ordering` database. Check with:
```sql
SELECT user, host FROM mysql.user;
GRANT ALL PRIVILEGES ON food_ordering.* TO 'root'@'localhost';
FLUSH PRIVILEGES;
```

**`Unknown database 'food_ordering'`**
The database does not exist. Run section 2.1, or check that your `DB_URL`
contains the database name.

**`Communications link failure`**
MySQL is not running. Check with `brew services list` or start it from
System Settings → MySQL.

**`Port 8080 was already in use`**
Another program is using port 8080 (often an older copy of this app that is
still running). Find and stop it:
```bash
lsof -nP -iTCP:8080 -sTCP:LISTEN
kill <the PID it prints>
```
or change `server.port` in `application.properties`.

**Nothing happens when you `export DB_PASSWORD=...`**
Make sure you `export` it in the **same terminal window** where you then run
`mvn spring-boot:run`.
